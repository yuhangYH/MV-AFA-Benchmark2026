# Results

This folder stores tabular outputs used to track MV-AFA controlled baseline
experiments.

## Current files

| File | Status | Notes |
|------|--------|-------|
| `controlled_baseline_chbmit_estimated_placeholder.csv` | Estimated placeholder | Draft CHB-MIT patient-independent comparison values from manuscript planning. |
| `controlled_baseline_chbmit_estimated_placeholder.tex` | Estimated placeholder | LaTeX version of the same draft table. |

The placeholder files are included to keep the manuscript draft and repository
aligned while DCRNN and TDA-CNN protocol-compatible runs are being finalized.
They should be replaced by completed outputs from
`benchmark/Controlled_DCRNN_TDACNN/run_baseline.py` before these numbers are
treated as final experimental evidence.
